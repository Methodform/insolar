# Инсоляр — какой сервер нужен и как запустить

> Обновлено: 2026-07-27. Цены — ориентировочные, проверяйте на калькуляторах провайдеров (меняются).

## Что вообще нужно обслуживать

Сейчас сайт статический (GitHub Pages). При переезде на свой сервер появляется бэкенд, потому что мы хотим:
- отдавать фронт (React-сборка) + лендинг + блог (лучше с SSR/пререндером — для SEO);
- модерируемый Q&A под статьями (БД + API);
- оплату «паспорта» (вебхук ЮKassa, только HTTPS);
- генерацию PDF-паспорта (headless Chromium — самый прожорливый по памяти кусок);
- прокси к НСПД (кадастр) и кэш Open-Meteo (ветер/климат), чтобы не дёргать чужие API на каждый заход.

## Требования к серверу (по этапам)

**Старт (только переезд текущего сервиса + блог, лёгкий API):**
- VPS 2 vCPU / 2–4 ГБ RAM / 40 ГБ SSD (NVMe), Ubuntu 22/24 LTS.
- Ориентир: ~300–600 ₽/мес.

**Рабочий (полный запуск: Q&A + оплата + генерация PDF-паспорта):**
- VPS 2–4 vCPU / 4–8 ГБ RAM / 60–80 ГБ NVMe.
- 8 ГБ RAM желательны из-за Chromium (Puppeteer) при генерации PDF; если PDF делать в очереди/асинхронно — хватит 4 ГБ.
- Ориентир: ~800–1800 ₽/мес.

Начать можно с младшего и вырасти вертикально за пару кликов — трафик на старте небольшой.

## Где брать (РФ — обязательно)

Персональные данные россиян по 152-ФЗ должны храниться на серверах в России, плюс иностранная авторизация под запретом (у нас и так Яндекс ID). Поэтому хостинг — российский:
- **Timeweb Cloud**, **Selectel** (от ~200 ₽), **Beget**, **Reg.ru** — простые VPS, есть защита от DDoS.
- **Yandex Cloud**, **VK Cloud** — если захочется managed-БД, объектное хранилище (S3 для PDF), автоскейл. Дороже, но меньше ручной работы.

Для старта достаточно обычного VPS у Timeweb/Selectel.

## Технический стек на сервере

- **ОС:** Ubuntu 22.04/24.04 LTS.
- **Nginx** — отдаёт статику фронта и проксирует на Node (reverse proxy), терминирует HTTPS.
- **Node.js 20 LTS** — бэкенд-API; держать под **PM2** (автоперезапуск) или в **Docker**.
- **PostgreSQL** — Q&A, проекты, платежи. (Можно managed-БД у облака, чтобы не бэкапить руками.)
- **Certbot / Let's Encrypt** — бесплатный SSL, автопродление.
- **Puppeteer/Chromium** — генерация PDF-паспорта (поставить системные зависимости; на слабой RAM — очередь задач).
- **S3-совместимое хранилище** (объектное) — для готовых PDF и картинок, чтобы не забивать диск (опционально, у Yandex/VK Cloud есть).

## Что ещё нужно кроме сервера

- **Домен .ru** (~200–1000 ₽/год) — покупать у РФ-регистратора; для .ru нужны паспортные данные.
- **HTTPS** — Let's Encrypt бесплатно.
- **Приём платежей:** ЮKassa/ЮMoney — нужен статус ИП или самозанятого и подключённый вебхук на бэкенде.
- **Уведомление в Роскомнадзор** как оператор перс. данных (сбор e-mail в Q&A/аккаунтах) — формальность, но по закону нужна.
- **Почта для уведомлений** (ответ на вопрос, чек оплаты) — SMTP-сервис (например, российский, чтобы не ловить блокировки).

## Чек-лист запуска

1. Купить домен .ru + VPS (Ubuntu LTS) у РФ-провайдера.
2. Настроить DNS домена на IP сервера.
3. Nginx + Certbot (HTTPS), базовый firewall (ufw), SSH по ключу.
4. Развернуть фронт (сборка Vite) + Node-API под PM2/Docker, PostgreSQL.
5. Прописать переменные: `VITE_YANDEX_CLIENT_ID`, ключи ЮKassa, доступ к БД.
6. Перенести Яндекс.Метрику, Вебмастер/Search Console на новый домен (переобход, sitemap).
7. Настроить бэкапы БД (ежедневно) и мониторинг (uptime).
8. Проверить SSR/готовый HTML статей (иначе SEO не работает) и скорость (PageSpeed).

## Ориентир по деньгам (в месяц)

- Старт: VPS ~300–600 ₽ + домен ~50 ₽/мес (в пересчёте) = **~400–700 ₽/мес**.
- Рабочий с PDF/оплатой: VPS ~1000–1800 ₽ + (опц.) managed-БД/S3 = **~1500–2500 ₽/мес**.

Комиссия ЮKassa за платежи — отдельно (процент с транзакции), не аренда.

# Ребрендинг: Инсоляр → SunPlan3D

> Решение: сервис переименовывается в **SunPlan3D**, домен **sunplan3d.ru** (свободен; insolar.ru занят Группой компаний ИНСОЛАР — смежная строительно-энергетическая ниша, конфликт).
> Написание: логотип **SunPlan3D** (латиница, одно слово) + постоянный русский слоган «Солнце, тени и ветер участка в 3D».
> Когда: замену в коде и контенте делаем **вместе с переездом на свой сервер** (не сейчас), чтобы не плодить промежуточные состояния. Пока — зафиксировано.
> Перед стартом: проверить знак «SunPlan» в Роспатенте (классы 9, 42); по желанию забрать sunplan3d.com.
> Обновлено: 2026-07-27.

## 1. Бренд-текст в интерфейсе и контенте

- Заменить «Инсоляр» → «SunPlan3D» везде: `landing.html`, `index.html` (React-app, шапка/футер/тексты), 13 статей блога, `blog.html`, документы (по желанию).
- Логотип-марка: сейчас «☉ Инсол**яр**» → «☉ SunPlan3D» (или новый знак). Проверить `.logo` в шапках всех страниц.
- Слоган/описания и OG-title/description — вписать русский слоган.
- «Редакция Инсоляр» в статьях (автор/подпись, источники) → «Редакция SunPlan3D».

## 2. Домен-зависимое (меняется на sunplan3d.ru)

- `canonical` во всех страницах → https://sunplan3d.ru/...
- Open Graph `og:url`, `og:image`, `twitter:image` → новый домен.
- JSON-LD: `url`, `mainEntityOfPage`, WebSite/Organization → новый домен.
- `sitemap.xml` — все `<loc>` на новый домен; `robots.txt` — строка Sitemap.
- Мета-верификация: заново подтвердить в Яндекс.Вебмастере и Google Search Console новый ресурс sunplan3d.ru (старые коды методформа не подойдут), заново отправить sitemap, переобход.
- **301-редиректы** со старых URL methodform.github.io/insolar/* → sunplan3d.ru/* (сохранить накопленную индексацию, если была).

## 3. Аналитика и инструменты

- Яндекс.Метрика — новый счётчик или сменить домен в текущем; цели перенести.
- Вебмастер / Search Console — новый ресурс, sitemap, IndexNow-ключ на новом домене.

## 4. Технические привязки к домену

- **Яндекс ID** (`yandexAuth.js`, `public/yandex-token.html`): `redirect_uri` и `YaSendSuggestToken(origin,…)` сейчас `https://methodform.github.io` → сменить на `https://sunplan3d.ru`; в OAuth-приложении Яндекса обновить Redirect URI и JavaScript Origin.
- Прокси кадастра (Cloudflare Worker / бэкенд) — CORS-origin на новый домен.
- Оплата ЮKassa — вебхук/return URL на новый домен.
- Почта уведомлений — адрес вида info@sunplan3d.ru.

## 5. Репозиторий и деплой

- Имя репозитория / пути (`insol/…`) — по желанию переименовать; обновить workflow деплоя под новый сервер (Nginx, а не GitHub Pages).

## 6. Порядок (в день переезда)

1. Домен sunplan3d.ru + сервер, HTTPS.
2. Глобальная замена бренд-текста и логотипа в коде/статьях.
3. Замена всех домен-зависимых URL (canonical/OG/JSON-LD/sitemap/robots).
4. Обновить Яндекс ID origin/redirect, прокси CORS, ЮKassa.
5. Подтвердить домен в Вебмастере/Search Console, отправить sitemap, IndexNow.
6. Настроить 301 со старого адреса (если использовался).
7. Проверить: битые ссылки, OG-превью, микроразметка, скорость.

## Примечание

Английское имя не мешает SEO: продвижение строим на бытовых русских запросах («расположение дома на участке», «отступ от забора», «климатический паспорт участка»), бренд-имя ключом быть не обязано. «3D» в имени — на пользу: подчёркивает наш дифференциатор (живая 3D-сцена) против статичных PDF-конкурентов.

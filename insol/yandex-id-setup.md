# Вход через Яндекс ID — как включить

Регистрация в Инсоляре сделана на **Яндекс ID** (мгновенная авторизация через виджет Яндекса).
Сайт статический (GitHub Pages, без бэкенда), поэтому используется клиентский token-флоу: пользователь
входит своим Яндекс-аккаунтом, мы получаем его имя и e-mail. Пароли мы не видим и не храним.

## Что уже готово в коде

- `react-app/src/yandexAuth.js` — загрузка SDK Яндекса и функция `loginWithYandex(clientId)`.
- `react-app/public/yandex-token.html` — вспомогательная страница-приёмник токена (деплоится в `/app/yandex-token.html`).
- В `App.jsx` — кнопка **«Войти с Яндекс ID»** в шапке, профиль и выход, хранение сессии в `localStorage`.

Осталось одно: получить `client_id`, зарегистрировав приложение у Яндекса.

## Шаги регистрации приложения (5 минут)

1. Откройте **https://oauth.yandex.ru/** → «Создать приложение».
2. Название: `Инсоляр`. Платформа: **Веб-сервисы**.
3. **Redirect URI** (Callback URL) — укажите точно:
   ```
   https://methodform.github.io/insolar/app/yandex-token.html
   ```
   (если сайт переедет на свой домен — поменяйте здесь и в `yandex-token.html`, строка `YaSendSuggestToken('https://ваш-домен', …)`).
4. **JavaScript Origin** (Web Origins): `https://methodform.github.io`
5. **Доступы (scopes)**:
   - `login:info` — имя и ID пользователя;
   - `login:email` — адрес электронной почты;
   - (по желанию) `login:avatar` — аватар.
6. Сохраните. Скопируйте **ClientID** (это и есть `client_id`).

## Куда вписать client_id

Вариант А — переменная окружения при сборке (рекомендуется). В GitHub Actions / локально:
```
VITE_YANDEX_CLIENT_ID=ваш_client_id
```
Вариант Б — прямо в код: `react-app/src/App.jsx`, строка
```js
const YANDEX_CLIENT_ID = (import.meta.env && import.meta.env.VITE_YANDEX_CLIENT_ID) || '';
```
замените `|| ''` на `|| 'ваш_client_id'`.

После этого кнопка «Войти с Яндекс ID» откроет виджет Яндекса и подставит профиль.

## Важно про ограничения

- **Подписки/оплата остаются демо.** Клиентский вход даёт только личность пользователя (кто вошёл),
  но не защищённое хранилище подписок — для этого нужен бэкенд или платёжный сервис (ЮKassa и т.п.).
  Сейчас Pro включается кнопкой-заглушкой; вход через Яндекс — это первый кирпич под будущие «Личный кабинет»
  и «Мои проекты».
- Токен живёт в браузере пользователя; мы не отправляем его на сервер (сервера нет).
- Виджет Яндекса не грузится на `localhost` без https — проверять удобнее на задеплоенном GitHub Pages.

## Как проверить после деплоя

1. Задеплоить (client_id уже вписан).
2. Открыть `https://methodform.github.io/insolar/app/`.
3. Нажать «Войти с Яндекс ID» → выбрать аккаунт → в шапке появится имя.
4. Обновить страницу — вход должен сохраниться (localStorage).

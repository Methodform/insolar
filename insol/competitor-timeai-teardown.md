# Разбор конкурента: TimeAI Климат (climatpassport.timeai.ai)

> Прямой конкурент: делает «климатический паспорт участка» по кадастровому номеру за 790 ₽ — ровно наша монетизация. Отчёт зрелый и подробный.
> Разобран пример отчёта (/example) 27.07.2026. Ниже — что реально полезно перенять, с привязкой к нашему стеку (Open-Meteo, астро-движок, полигон участка, 3D-сцена).

## Что у них в отчёте (8 блоков + допы)

1. Геометрия: план из НСПД, длины всех сторон, площадь, периметр, габариты (з-в × ю-с), число сторон.
2. Спутник: кадастровые границы на Esri World Imagery + архивные версии (Wayback 2014/2018/2022/2026) — сравнить, как менялся участок.
3. Инсоляция: 3D-купол неба, пути солнца на солнцестояния/равноденствия, восход/закат/высота по 4 датам, световой день по месяцам (бар-чарт).
4. Ветер: роза по сезонам и по месяцам (16 румбов, Open-Meteo 2011–2026), роза скоростей, господствующий зимой/летом, макс порыв, % штиля.
5. Климат: t° и осадки по месяцам, безморозный период, отопительный сезон (градусо-сутки), GDD10, снежный покров, комфортные/дождливые дни, «окно для стройки».
6. Нормы: таблицы отступов (СП 53.13330, СП 42.13330, СанПиН, пожарные).
7. Рекомендации (текст, ИИ): где дом, терраса, сад, ветрозащита, энергоэффективность, дренаж/снег.
8. Эскиз размещения: 2 честных варианта (сбалансированный / больше солнца) с плюсами и компромиссами, каждый печатается в PDF.
Плюс: ИИ-чат по паспорту (демо), брендированный white-label PDF (убрать их лого → своё), выбор A4/A3, честный блок источников и оговорок.

---

## Взять в первую очередь (дёшево + высокая ценность, наш стек уже позволяет)

- **Световой день по месяцам** (бар-чарт, часы/мес). Считается из широты нашим астро-движком. Простой и наглядный блок в паспорт.
- **Восход/закат/высота солнца на 4 сезонные даты** (22.12 / 21.03 / 22.06 / 23.09) — таблица. Ровно ложится на «нормативные даты», о которых говорили. Дёшево.
- **Климатический профиль из Open-Meteo** (мы уже дёргаем этот API для ветра): t°/осадки по месяцам, безморозный период, отопительный сезон в градусо-сутках, снежный покров, комфортные/дождливые дни. Высокая воспринимаемая ценность, данные бесплатные.
- **«Окно для стройки»** — лучшие месяцы для «мокрых» работ (фундамент/кладка) по t° и осадкам. Очень конкретный, продающий вывод; считается из того же архива.
- **Расширенная статистика ветра**: средняя скорость по румбам, господствующий зимой/летом, макс порыв, % штиля. У нас роза ветров уже есть — добираем цифры почти бесплатно.
- **«Главный вывод» абзацем в начале** отчёта (климат/риски/возможности) — хорошая рамка, задаёт тон.
- **Длины всех сторон + габариты на плане** — из полигона считается сразу, добавляет солидности.

## Взять во вторую очередь (среднее усилие, сильная отдача)

- **Варианты размещения построек** (2–3 честно разных: «сбалансированный», «больше солнца/сада») с плюсами и компромиссами. У нас расстановка объектов уже есть — авто-генерация пары раскладок по солнцу/ветру/отступам это наш дифференциатор в паспорте.
- **Брендированный white-label PDF** (своё лого вместо нашего) — прямое попадание в сегмент 5 (ландшафтники/риелторы) и в B2B-монетизацию. У конкурента под это отдельная статья и продажа.
- **Архивные спутниковые снимки для сравнения** (как менялся участок) — ценно для сегмента «покупка участка». НО: у них Esri (иностранный) — нам брать российскую подложку (Яндекс/2ГИС Спутник), см. разбор про карты.

## Позже / осторожно

- **ИИ-чат по паспорту** — модно и они этим торгуют, но нужен LLM-бэкенд (стоимость) и жёсткие оговорки честности (они сами пишут: чат «не видит рельеф, сети, геологию»). Не ядро; после базовой монетизации.
- **PDF A4/A3** — мелочь, добавить легко, когда будет генерация PDF.

## Чего НЕ копировать

- Иностранную спутниковую подложку Esri — для РФ брать Яндекс/2ГИС.
- Полностью статичный PDF-подход как единственный формат: **наш козырь — живая 3D-сцена с тенями и потоком ветра в реальном времени и таймбаром**, чего у них нет (у них картинки и PDF). Паспорт-контент перенимаем, но точкой входа и «вау» оставляем интерактив.

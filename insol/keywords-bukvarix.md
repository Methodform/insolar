# Инсоляр — семантическое ядро (Bukvarix API)

> Источник: Bukvarix, бесплатный API `http://api.bukvarix.com/v1/keywords/` (GET, `api_key=free`).
> Метод: простой поиск по 9 сид-фразам, широкое соответствие. Цифры — «Частотность Весь мир» (широкая, ≈ месяц), в скобках при наличии — «!точная !частотность».
> Темы по запросу: расположение дома, тени, споры, здоровье, загородная жизнь + «почему это важно».
> Оговорка: частотности Bukvarix — оценочные и по региону «Весь мир»; перед бюджетом сверить в Яндекс.Wordstat по РФ. Обновлено: 2026-07-26.

## ГЛАВНЫЙ ВЫВОД (почему это важно)

1. **Слово «инсоляция» — высокочастотное (~27 500 широкая, ~2 694 точная), но его объём делают НЕ частники-застройщики.** Уточнено по данным API (см. раздел «Разбор частоты слова “инсоляция”»). Пирог из 27 тысяч складывают: информационный интент `инсоляция это` 5842 / `инсоляция что` 3466 (определение, студенты) и профессиональный `расчёт инсоляции` ~4358 / `инсоляция помещений` 2116 / `инсоляция зданий` 1899 / `СанПиН` ~760 (архитекторы, экспертиза) — плюс вовсе чужое `инсоляция кожи` 258 (медицина). Наш частник на участке — лишь малый срез (`инсоляция участка` 650, `земельного участка` 244). → Для **beachhead (частник)** SEO строим на **бытовом языке** (`расположение дома на участке` ~3679, `отступ от забора` ~4240, `тень на участке` ~3065, `нормы застройки` ~912), а весь массив «инсоляция» берём отдельно — под **профи-сегмент** и под **информационную статью-определение**.
2. **Три денежных пласта спроса:** (а) размещение построек, (б) **нормы/отступы**, (в) **споры с соседями**. Все три — большие и «горячие» (транзакционные, человек реально строит/судится). Это подтверждает кластеры 1–2 контент-плана и «судебные» ролики v3.
3. **Баня — неожиданно сильный чистый интент:** `расположение бани на участке` ~1160 (точная 105!) — отдельный лендинг + ролик оправданы.
4. **«Затенение соседнего участка» — низкочастотный, но самый конверсионный, конфликтный интент** (человек уже в споре). Мало трафика, но горячий и близкий к оплате отчёта/экспертизы.
5. **«Здоровье» как поисковый интент в этой нише почти отсутствует.** Люди ищут практику (куда/сколько/нормы), а не «солнце и здоровье». → Здоровье использовать как **крючок в роликах** (охваты, v2/v3), но НЕ как SEO-ядро; продавать через ошибку/нормы/споры/деньги.

## Как использовать (связка с контент-планом и рекламой)

- **SEO-заголовки — на бытовом ядре:** «расположение дома на участке», «отступ от забора», «нормы застройки», «тень на участке», «расположение бани». «Инсоляцию» — в подзаголовки/текст (экспертность + перехват).
- **Отдельные посадочные:** баня (высокий чистый спрос), отступы/нормы, споры с соседями, тень/что посадить.
- **Горячий конверсионный трафик:** «затенение соседнего участка», «тень на участке соседа», «нарушение инсоляции», «экспертиза инсоляции», «расчёт инсоляции онлайн» — низкий объём, но человек уже в проблеме/споре → вести прямо на проверку и платный отчёт.
- **Перехват конкурента:** запросы с «сундук» → страница-сравнение «Инсоляр vs СмотриСундук».
- **Здоровье** оставляем крючкам в роликах (v2/v3), в SEO не тащим — спроса нет.

## Технические заметки по API (для повторного сбора)
- Эндпоинт простого поиска: GET `http://api.bukvarix.com/v1/keywords/?q=<фраза>&api_key=free&format=csv&num=<N>`; расширенный (список слов) — POST `/v1/mkeywords/` (Content-Type `application/x-www-form-urlencoded`, `q` — фразы построчно, лимит 100 строк в бесплатной версии).
- Бесплатный ключ: `free`; фильтры по частотности/длине — только в платной версии (иначе 402).
- Есть лимит частоты: при плотных запросах отдаёт **429** — делать паузы между вызовами.
- `web_fetch` не возвращает тело CSV/JSON (не-HTML) — собирать через прямой GET (curl) в сэндбоксе.
